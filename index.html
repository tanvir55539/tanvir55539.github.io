Bachelor thesis

A Quantum-Inspired Fidelity-Density Framework with Confidence-Aware Swarm Collaboration for Decentralized IoT Anomaly Detection

  • Built a benign-reference, quantum-inspired anomaly detector that combines fidelity similarity with local density deviation for decentralized IoT intrusion detection.
  • Added confidence-aware swarm peer collaboration, where devices verify alarms at inference time using confidence-weighted consensus and local anomaly evidence.
  • Evaluated on CICIoT2023 and X-IIoTID against one-class baselines, with repeated-seed experiments, statistical analysis and an NS-3 network-level validation.
  • Anomaly detection
  • IoT security
  • CICIoT2023
  • X-IIoTID
  • NS-3

Bachelor capstone

SmartVision: Multimodal Mobile Assistant for Visually Impaired Users

  • Built a cross-platform Flutter app that gives visually impaired users real-time navigation, scene description and obstacle detection.
  • Combined the Google Gemini API for online scene understanding with TensorFlow Lite for offline, on-device object detection and proximity awareness.
  • Delivered feedback through text-to-speech and haptic vibration, so guidance arrives as both sound and touch.
  • Flutter
  • Dart
  • Gemini API
  • TensorFlow Lite
